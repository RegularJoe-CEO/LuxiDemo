# Tools

Development and verification utilities for Luxi Edge.

## Scripts

- **`client_python_example.py`** - Example Python client demonstrating API usage with precision parameter support
- **`verify_benchmark_freshness.sh`** - Validates benchmark data is up-to-date
- **`verify_benchmarks.sh`** - Comprehensive benchmark validation script

## Usage

These tools are primarily for:
- Testing API endpoints during development
- Verifying benchmark data integrity
- Demonstrating client integration patterns

For agent bootstrap and smoke testing, see [`../scripts/`](../scripts/).
