Deployment Summary

  • Language: Rust core with optional Python tooling
  • Deployment targets: x86-64 + ARM64 (SIMD) and NVIDIA GPUs
  • Interfaces: REST (OpenAPI), gRPC (roadmap), edge binary SDK
  • Support: Enterprise SLAs, email: support@luxi-edge.com

Roadmap

  • 2025 Q2 — Expanded GPU coverage (H100/H200)
  • 2025 Q3 — AMD ROCm optimization
  • 2025 Q4 — Managed SaaS endpoints with energy telemetry dashboard
