🚀 RUNPOD GPU BENCHMARK - QUICK START
=====================================

1. DOWNLOAD THE PACKAGE:
   - Download: runpod_luxi_benchmark.tar.gz (37KB)
   - From: /workspaces/LuxiEdge/runpod_luxi_benchmark.tar.gz

2. UPLOAD TO RUNPOD:
   - Go to: https://www.runpod.io/console/pods
   - Start a pod with: RTX 4000 / L4 / Any GPU
   - Template: PyTorch or CUDA (has Rust pre-installed)
   - Upload the tar.gz file to /workspace/

3. ON RUNPOD, RUN THESE 3 COMMANDS:
   
   cd /workspace
   tar -xzf runpod_luxi_benchmark.tar.gz
   bash runpod_deploy.sh

4. SIT BACK - IT WILL:
   ✅ Install dependencies (pynvml, numpy, requests)
   ✅ Build Luxi Edge (cargo build --release)
   ✅ Start server on port 8080
   ✅ Run 4M GPU benchmark with power monitoring
   ✅ Show results: ops/sec, latency, power, SIMD gap

EXPECTED OUTPUT:
================

============================================================

Average ops/sec (Rhai): ~2,000

TROUBLESHOOTING:
