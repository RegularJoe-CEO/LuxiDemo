Luxi Demo

Public demo builds for LuxiEdge math, Waller geodesic attention, orbital solves, edge robotics, and energy-aware transformers. Same inputs give the same SHA256 hash across platforms. These binaries expire after 10 days.

Demo only. Not for production. Full operator sets require a license.

Quick start

chmod +x luxiedge-lite-macos-arm64
./luxiedge-lite-macos-arm64 --port 9090
curl -X POST http://localhost:9090/evaluate \
  -H "Content-Type: application/json" \
  -d '{"expr":"sin(x)","values":[0.5,1.0,1.57,2.0,3.14],"precision":"f32"}'

Run validation:

./luxiedge-demo-macos-arm64 validate
