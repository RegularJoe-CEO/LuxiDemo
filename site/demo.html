Luxi Book primary

CSV position book → European Black-Scholes / Black-76 → five Greeks → SHA-256 receipt. You bring T, r, and σ. No live feed. No IV. No VaR. Not a fund desk.

CPU is default. On Linux with NVIDIA you can build CUDA and run --mode gpu (no silent CPU fallback). Mac is CPU-only.

Measured on example_book.csv only (2026-08-15): the same receipt 4a21b1e708fa5c694bf48237df5e5bd3b94599e6273d07986283c6c6b8e3c97a on Mac Mini CPU, RunPod x86 CPU, A100-SXM4-80GB, H100 80GB HBM3, and H200 (two GPU runs each). ATM_CALL 10.4505835721856215. Kernel black_scholes_book_kernel. Device Φ is the same series as CPU (not CUDA libm for those five).

Non-claim: this book, these boxes, this kernel — not “all GPUs always match.”

macOS ARM64 (CPU) Linux x86_64 (CPU) Linux x86_64 (CUDA) example_book.csv

Checksums: macOS · Linux CPU · Linux CUDA. Mac is CPU-only. CUDA Linux build needs a live NVIDIA driver at runtime. Unsigned. 

# Mac (CPU)
chmod +x luxi-book-macos-arm64
./luxi-book-macos-arm64 price --book example_book.csv --out report.csv --receipt receipt.json

# Linux CPU
./luxi-book-linux-x86_64 price --book example_book.csv --out report.csv --receipt receipt.json

# Linux + NVIDIA (CUDA binary)
./luxi-book-linux-x86_64-cuda price --book example_book.csv --out report.csv --receipt receipt.json --mode gpu

LuxiRisk freebie

Free offline CLI for leveraged crypto / retail traders — not the Quant book, not institutional. Three formulas: liq, size, risk. Each answer gets an Ed25519 lxr1_ calculation receipt.

macOS ARM64 Linux x86_64 Windows 
chmod +x luxirisk-macos-arm64
shasum -a 256 -c luxirisk-macos-arm64.sha256
./luxirisk-macos-arm64 liq --side long --entry 65000 --leverage 10
# → liquidation price + lxr1_ receipt
