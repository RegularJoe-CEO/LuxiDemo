Quick Summary

eRock is a Rust/WASM service that offloads numerical workloads to CPU for fast, energy-efficient inference at the edge and hyperscale. This preview is focused on engineers: clean facts, verified metrics, and integration pointers.

Key Capabilities

  • Hardware-agnostic CPU offload engine
  • TEE and ZK-backed security posture (conceptual)
  • Minimal runtime footprint for embedded/edge

Example (integration sketch)

// Pseudocode: call eRock as a microservice

  "x": [ ... ]
}
