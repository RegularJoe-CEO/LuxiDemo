Quick Summary

Luxi Edge is a Rust-based microservice that provides ultra-fast numeric computation for edge and data center deployments. This preview is focused on engineers: clean facts, verified metrics, and integration pointers.

Key Capabilities

  • SIMD-accelerated expression evaluation
  • Deterministic root-finding with auto-bracketing
  • Minimal runtime footprint for embedded/edge

Example (integration sketch)

// Call Luxi Edge as a microservice
POST /evaluate
Content-Type: application/json
{
  "expr": "x^2 + 3*x - 5",
  "x": [0, 1, 2, 3, 4]
}
// returns numeric results (json)
